# Chrome 扩展开发

> 本章记录一个完整的 Chrome 扩展项目：**video-sniffer**（视频嗅探下载器）。
>
> 它从零起步、边写边踩坑，最终做到：在任意视频网站上嗅探出视频/音频资源，
> 下载、合并、封装成带音轨的 MP4。
>
> 本章的写法是**先讲原理、再看实战**。所有接口返回值、码率、盒子结构、
> 文件大小都是真实抓取的数据，不是推测；每一处代码改动都标注了它在
> video-sniffer 项目里的位置。

---

## 这个项目在解决什么问题

你在浏览器里看一个视频，画面就出来了。看起来很自然，但**视频文件并不在网页里**——
网页只是一个播放器，它背后不停地跟服务器要数据、拼数据、解数据。

video-sniffer 做的事，一句话概括：

> **在数据流到浏览器之前，偷偷看一眼，把「视频是从哪个网址来的」记下来。**

记下来之后就能：

- 点一下把整个视频下载到硬盘；
- 把散落的音视频重新拼成一个能播的 MP4；
- 边看边录，把正在播的部分存下来。

配套工程是一个 4 万行量级的 MV3 扩展，涉及页面主世界/隔离世界双注入、
Service Worker 生命周期、offscreen 文档、ffmpeg.wasm 封装、DNR 改写请求头、
以及三个站点的协议逆向。**这些坑每一个都值得单独写一篇。**

## 关于代码路径引用

本章里出现的 `` `src/common/dash.js:91` `` 这类写法，**指的是 video-sniffer
项目里的文件与行号**，不是本章的页面。

video-sniffer 的目录结构大致是：

```text
video-sniffer/
├── manifest.json                 MV3 清单：权限、双内容脚本、CSP
├── src/
│   ├── common/                   ← 纯逻辑，无 DOM / 无 chrome API，可单测
│   ├── content/                  ← 页面侧（page-hook / bridge）
│   ├── background/               ← 后台（路由、登记表、下载编排、DNR）
│   ├── offscreen/                ← 真正干活的地方（下载、ffmpeg 封装）
│   ├── popup/                    ← 工具栏弹窗
│   └── options/                  ← 设置页
├── test/                         ← 单元测试
├── tools/                        ← CDP 客户端、端到端脚本、诊断工具
└── docs/                         ← 本章的原始素材
```

**一条铁律**：`src/common/` 里的文件必须能在 Node 里裸跑（不 import 任何 chrome API）。
所有跨层可复用的判断都往这里放，测试也只测这一层——这样绝大多数逻辑不需要开浏览器就能验证。

## 术语速查

| 词 | 大白话 |
|---|---|
| **容器（container）** | 信封。MP4 / MKV / WebM / FLV / TS 说的是「怎么包装」 |
| **编码（codec）** | 语言。H.264 / HEVC / AV1 / AAC / Opus 说的是「怎么压缩」 |
| **轨道（track）** | 一条独立的流。视频轨只有画面，音频轨只有声音 |
| **分片（segment）** | 切开的一小块数据，通常几秒 |
| **清单（manifest）** | 一份写明整集所有流地址的文件，如 `master.m3u8` / `.mpd` |
| **封装（remux）** | 内容一字节不改，只换信封。快、无损 |
| **转码（transcode）** | 重新编码。慢、有损、质量下降 |
| **MSE** | 浏览器接口，网页自己把数据一段段喂给播放器。数据只在内存里 |
| **Blob URL** | `blob:https://...` 内存句柄，页面关掉就没了 |
| **DRM** | 数字版权管理。文件是密文，浏览器播放时解密 |

## 边界与红线

video-sniffer **只**使用站点自己提供的、当前登录账号**有权观看**的普通播放地址。

- ❌ 不做任何解密，不提取密钥，不修改播放器；
- ❌ 不绕过付费 / 会员清晰度限制；
- ❌ 不使用站点的 DRM 协商接口来拿加密流（番剧页改走普通播放接口，见 [05](05-bilibili-bangumi.md)）。

账号没权限时，服务器给什么就是什么——通常是一段低码率的免费片段。
本章讨论的所有方法都建立在这个前提上。
